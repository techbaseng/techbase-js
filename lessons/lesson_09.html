Phase 1 of 2
const basics and best practice
📖 Concept

const declares a binding that cannot be reassigned. It does NOT make the value immutable — objects and arrays can still be modified. Use const by default for everything; switch to let only when you know you'll reassign. This makes code more predictable: when you see const, you know the binding won't change.

script.js
// Primitives — truly immutable with const
const TAX_RATE  = 0.075;
const SITE_NAME = 'Techbase Academy';
const IS_ACTIVE = true;
// TAX_RATE = 0.05;  // ❌ TypeError: Assignment to constant variable

// Objects — binding is const, contents can change
const student = { name: 'Amina', score: 94 };
student.score = 95;     // ✅ modifying a property — fine
student.grade = 'A';    // ✅ adding a property — fine
// student = {};         // ❌ reassigning the binding — not fine

// Arrays — same rule
const scores = [90, 85, 92];
scores.push(88);         // ✅ adding to array — fine
scores[0] = 95;          // ✅ modifying element — fine
// scores = [1, 2, 3];   // ❌ reassigning — not fine

// Object.freeze() — truly immutable
const CONFIG = Object.freeze({ host: 'localhost', port: 3000 });
CONFIG.host = 'production'; // silently ignored in sloppy mode
console.log(CONFIG.host);   // still 'localhost'

Phase 2 of 2
const in loops and destructuring
📖 Concept

const works in for...of loops because each iteration creates a NEW binding (not a reassignment). Destructuring with const: const {name, score} = student. Cannot use const in a regular for loop (the counter changes).

script.js
// ✅ const in for...of (new binding per iteration)
const fruits = ['mango', 'guava', 'pawpaw'];
for (const fruit of fruits) {
  console.log(fruit);  // mango, guava, pawpaw
}

// ✅ const in forEach
fruits.forEach(const fruit => {  // actually: arrow functions
  console.log(fruit.toUpperCase());
});

// ✅ Destructuring with const
const { name, score } = student;
const [first, , third] = scores;  // skip second with empty

// ❌ Regular for loop needs let (counter changes)
for (let i = 0; i < 5; i++) {
  // i = i + 1 happens — can't be const
}

// Import constants from modules
// import { MAX_SIZE, DEFAULT_TIMEOUT } from './config.js';
