Phase 1 of 2
Arithmetic and assignment operators
📖 Concept

Arithmetic: + - * / % ** ++ --. Division always returns a float. Modulus % = remainder. Exponentiation ** = power. Assignment shortcuts: += -= *= /= %= **=. Increment: x++ (post — use then add) vs ++x (pre — add then use).

script.js
let a = 10, b = 3;

// Arithmetic
console.log(a + b);   // 13
console.log(a - b);   // 7
console.log(a * b);   // 30
console.log(a / b);   // 3.333...
console.log(a % b);   // 1  (10 = 3×3 + 1)
console.log(a ** b);  // 1000  (10³)

// Assignment shortcuts
let x = 10;
x += 5;   // x = 15
x -= 3;   // x = 12
x *= 2;   // x = 24
x /= 4;   // x = 6
x **= 2;  // x = 36

// Increment/decrement
let count = 5;
console.log(count++); // 5 (returns THEN increments)
console.log(count);   // 6
console.log(++count); // 7 (increments THEN returns)

Phase 2 of 2
Comparison and logical operators
📖 Concept

Comparison: == != > < >= <=. Type-coercing: == (avoid — '5'==5 is true!). Strict: === !== — always prefer these. Logical: && (AND), || (OR), ! (NOT). Short-circuit: a && b returns b only if a is truthy; a || b returns a if truthy, otherwise b. Nullish coalescing: ?? returns right side only if left is null/undefined.

script.js
// Always use === (strict equality)
console.log(5 === 5);    // true
console.log(5 === '5');  // false — different types
console.log(5 ==  '5');  // true  — type coercion (avoid!)

// Logical operators
let age = 25, hasID = true;
console.log(age >= 18 && hasID);  // true (both conditions)
console.log(age < 18 || hasID);   // true (at least one)
console.log(!hasID);               // false (NOT)

// Short-circuit evaluation
let user = null;
let name = user && user.name;    // null (user is falsy)
let display = name || 'Guest';   // 'Guest' (name is falsy)

// Nullish coalescing ?? (only null/undefined, not 0 or '')
let score = 0;
let points = score ?? 100;  // 0 (score is NOT null/undefined)
let old    = score || 100;  // 100 (score is falsy — wrong!)
