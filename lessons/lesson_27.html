Phase 1 of 2
sort() compare function
📖 Concept

sort() without arguments converts to strings — gives wrong results for numbers! Always provide (a,b) => a-b for ascending, (a,b) => b-a for descending. String sort: localeCompare() for proper alphabetical (handles accents). Sort is IN PLACE — it modifies the original array.

script.js
const nums = [10, 1, 21, 2];
nums.sort();              // [1, 10, 2, 21] ← WRONG (string sort)
nums.sort((a,b) => a-b); // [1, 2, 10, 21] ← correct ascending
nums.sort((a,b) => b-a); // [21, 10, 2, 1] ← descending

// String sort
['banana','apple','mango'].sort();                    // alphabetical
['Banana','apple'].sort((a,b)=>a.localeCompare(b));  // case-insensitive

// Object sort
const students = [{name:'Tunde',score:52},{name:'Amina',score:94}];
students.sort((a,b) => b.score - a.score);   // by score desc
students.sort((a,b) => a.name.localeCompare(b.name)); // by name

// Preserve original — sort a copy
const sorted = [...nums].sort((a,b) => a-b);

Phase 2 of 2
Stable sort and custom comparators
📖 Concept

Modern JS sort is stable — equal elements keep their original order. Useful pattern: sort by multiple criteria: (a,b) => a.dept.localeCompare(b.dept) || b.score-a.score — sort by department first, then score within department.

script.js
// Multi-key sort
const data = [
  {dept:'Eng', score:85},
  {dept:'Art', score:72},
  {dept:'Eng', score:90},
];
data.sort((a,b) =>
  a.dept.localeCompare(b.dept) || b.score - a.score
);
// Art:72, Eng:90, Eng:85 — dept first, then score desc

// Random shuffle (Fisher-Yates)
function shuffle(arr) {
  const a = [...arr];
  for (let i = a.length-1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i+1));
    [a[i],a[j]] = [a[j],a[i]];
  }
  return a;
}
