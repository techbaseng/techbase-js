Phase 1 of 2
if, else if, else
📖 Concept

if(condition) runs block when condition is truthy. else if chains more conditions. else catches everything else. Nest sparingly — more than 3 levels is a code smell. Early return pattern: return early on failure cases, keep the happy path at the end.

script.js
// Basic if/else
let score = 75;
if (score >= 70) {
  console.log('A');
} else if (score >= 60) {
  console.log('B');
} else if (score >= 50) {
  console.log('C');
} else {
  console.log('F');
}

// Early return (guard clauses)
function getDiscount(user) {
  if (!user) return 0;          // guard: no user
  if (!user.isActive) return 0; // guard: inactive
  if (user.role === 'admin') return 0.5;
  if (user.isPremium) return 0.2;
  return 0.05; // default
}

// Single-line (only for simple cases)
if (x > 0) doSomething();

Phase 2 of 2
Ternary and nullish coalescing
📖 Concept

Ternary: condition ? valueIfTrue : valueIfFalse. Use for simple assignments, not complex logic. Nest maximum once. ?? for null/undefined defaults. ?.optional chaining to safely access nested properties without if checks.

script.js
// Ternary — inline if/else
const grade = score >= 70 ? 'Pass' : 'Fail';
const label = score >= 90 ? 'A' : score >= 70 ? 'B' : 'C'; // nested (ok)

// Use ternary for values, not statements
// ✅ good
const msg = isLoggedIn ? 'Welcome!' : 'Please log in';
// ❌ avoid
isLoggedIn ? doLongThing() : doOtherLongThing(); // use if/else

// ?? nullish coalescing (null/undefined only)
const name = user.name ?? 'Anonymous';
const port = config.port ?? 3000;

// ?. optional chaining
user?.address?.city     // undefined if user or address is null
arr?.[0]?.name          // safe array access
fn?.()                  // safe function call
