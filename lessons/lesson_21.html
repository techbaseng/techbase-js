Phase 1 of 2
Number types and limits
📖 Concept

JS has one number type: 64-bit float (IEEE 754). Integer precision up to 2⁵³-1 (Number.MAX_SAFE_INTEGER = 9007199254740991). Larger: use BigInt. Special values: Infinity, -Infinity, NaN. Check: isFinite(), isNaN(). Hex: 0xFF. Octal: 0o77. Binary: 0b1010.

script.js
Number.MAX_SAFE_INTEGER;  // 9007199254740991
Number.MIN_SAFE_INTEGER;  // -9007199254740991
Number.MAX_VALUE;         // ~1.8e+308
Number.EPSILON;           // ~2.22e-16

// Checking special values
isNaN(NaN);        // true
isNaN('hello');    // true  (converts then checks)
Number.isNaN(NaN); // true  (strict — no conversion)
Number.isNaN('hello'); // false (correct!)
isFinite(1/0);     // false
Number.isFinite(42); // true

// Number bases
0xFF;     // 255 (hex)
0o77;     // 63  (octal)
0b1010;   // 10  (binary)

// Scientific notation
1e6;    // 1000000
1.5e-3; // 0.0015

// Number methods
(3.14159).toFixed(2);      // "3.14"
(1234567).toLocaleString(); // "1,234,567"
(255).toString(16);         // "ff"  (to hex)
(10).toString(2);           // "1010" (to binary)

Phase 2 of 2
Math object
📖 Concept

Math has 30+ methods. Key: Math.random() — float 0 to <1. Random integer: Math.floor(Math.random() * max). Range: Math.floor(Math.random() * (max - min + 1)) + min. Rounding: round, floor, ceil, trunc. Trig: sin, cos, tan. Log: log, log2, log10.

script.js
// Random numbers
Math.random();                              // 0.xxx (0 ≤ x < 1)
Math.floor(Math.random() * 6) + 1;         // dice: 1–6
Math.floor(Math.random() * (100 - 50 + 1)) + 50; // 50–100

// Rounding
Math.round(4.5);   // 5
Math.floor(4.9);   // 4 (towards -∞)
Math.ceil(4.1);    // 5 (towards +∞)
Math.trunc(4.9);   // 4 (towards 0, same for positive)
Math.trunc(-4.9);  // -4 (truncates decimal part)

// Power & roots
Math.pow(2, 10);   // 1024
Math.sqrt(25);     // 5
Math.cbrt(27);     // 3

// Min / max / absolute
Math.max(3, 1, 9, 2);  // 9
Math.min(3, 1, 9, 2);  // 1
Math.abs(-42);          // 42
Math.hypot(3, 4);       // 5 (Pythagorean)
Math.PI;                // 3.141592...
Math.E;                 // 2.718281...
