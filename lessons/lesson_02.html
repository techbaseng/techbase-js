Phase 1 of 2
Internal and external scripts
📖 Concept

JS can go three places: (1) Inline: onclick='alert("hi")' in HTML — avoid for anything complex. (2) Internal: <script> tag in the HTML file. (3) External: <script src='app.js'></script> — best practice. Always place <script> before </body> so HTML loads first.

index.html
<!DOCTYPE html>
<html>
<head>
  <title>JS Where To</title>
  <!-- External CSS -->
  <link rel="stylesheet" href="style.css">
  <!-- DON'T put script here unless using defer/async -->
</head>
<body>
  <h1>Hello!</h1>
  <button onclick="greet()">Click me</button> <!-- inline handler -->

  <!-- Best practice: script just before </body> -->
  <script src="app.js"></script>
</body>
</html>
✏️ Your Task

Create two files: index.html and app.js. In app.js write console.log('Script loaded!') and link it in HTML. Open DevTools Console to see the message.

Phase 2 of 2
defer and async
📖 Concept

When script is in <head>, use defer to wait for HTML to parse: <script src='app.js' defer>. Use async for independent scripts (analytics). defer preserves script order; async doesn't. Modern best practice: put scripts in <head> with defer.

index.html
<!-- In <head> — use defer -->
<script src="app.js" defer></script>

<!-- async: loads in parallel, runs immediately when ready -->
<!-- Use for analytics, ads, independent scripts -->
<script src="analytics.js" async></script>

<!-- type="module" implies defer automatically -->
<script type="module" src="main.js"></script>

<!-- DOMContentLoaded waits for HTML to parse -->
<script>
  document.addEventListener('DOMContentLoaded', function() {
    // Safe to access DOM here
    document.querySelector('h1').style.color = '#d97706';
  });
</script>
✏️ Your Task

Move your <script> tag to the <head> and add the defer attribute. It should still work. Now remove defer and try to select an element that comes after the script — it will be null without defer!
