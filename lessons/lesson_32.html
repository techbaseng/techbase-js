Phase 1 of 2
Truthy and falsy
📖 Concept

Only 8 falsy values: false, 0, -0, 0n, '', null, undefined, NaN. Everything else is truthy — including 'false', [], {}, -1! Use Boolean(val) or !!val to convert.

script.js
// The 8 falsy values
Boolean(false);     // false
Boolean(0);         // false
Boolean(-0);        // false
Boolean(0n);        // false (BigInt zero)
Boolean('');        // false (empty string)
Boolean(null);      // false
Boolean(undefined); // false
Boolean(NaN);       // false

// Surprising truthy values!
Boolean('false');   // true (non-empty string)
Boolean('0');       // true (non-empty string)
Boolean([]);        // true (empty array!)
Boolean({});        // true (empty object!)
Boolean(-1);        // true (non-zero number)

// !! double-negation to boolean
!!0;      // false
!!'';     // false
!!'hi';   // true
!![];     // true

Phase 2 of 2
Boolean logic patterns
📖 Concept

Short-circuit patterns: a && b returns a if falsy, else b. a || b returns a if truthy, else b. a ?? b returns b only if a is null/undefined. Use for defaults: const name = input || 'Guest'. Guard: user && user.name.

script.js
// Default values
const name = '' || 'Guest';      // 'Guest' ('' is falsy)
const score = 0 || 100;          // 100 (0 is falsy — wrong!)
const score2 = 0 ?? 100;         // 0 (?? only checks null/undefined)

// Guard — access property safely
const user = null;
const username = user && user.name; // null (short-circuits)

// Optional chaining (modern alternative)
const username2 = user?.name;    // undefined (safe)
const city = user?.address?.city; // undefined (nested)

// Conditional rendering pattern
const isLoggedIn = true;
isLoggedIn && showDashboard();  // only calls if true

// Convert truthy to strict boolean
const hasItems = !!cart.length;  // true/false not a number
