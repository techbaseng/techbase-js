Handle user interactions with DOM event listeners

📚 2 phases 🏗️ Build: My Event Playground
Phase 1 of 2
addEventListener
📖 Concept

Attach events with element.addEventListener(type, handler). Common events: click, dblclick, mouseover, mouseout, keydown, keyup, change, input, submit, focus, blur, resize, scroll. The handler receives an event object with useful properties: event.target, event.key, event.clientX/Y, event.preventDefault().

script.js
const btn = document.getElementById('my-btn');

// Add listener
btn.addEventListener('click', function(event) {
  console.log('Clicked!', event.target);
});

// Arrow function (shorter)
btn.addEventListener('click', e => {
  e.target.style.background = '#d97706';
});

// Keyboard events
document.addEventListener('keydown', e => {
  console.log('Key:', e.key, 'Code:', e.code);
  if (e.key === 'Enter') submitForm();
  if (e.ctrlKey && e.key === 's') {
    e.preventDefault();  // prevent browser save
    saveData();
  }
});

// Remove listener
function handleClick() { console.log('clicked'); }
btn.addEventListener('click', handleClick);
btn.removeEventListener('click', handleClick); // must be same reference

Phase 2 of 2
Event delegation
📖 Concept

Instead of adding listeners to every child, add ONE listener to the parent and use event.target to identify which child was clicked. More efficient — works even for dynamically added elements. Use event.target.closest('.class') to handle clicks on child elements inside the target.

script.js
// ❌ Individual listeners (bad for many items)
const items = document.querySelectorAll('.item');
items.forEach(item => {
  item.addEventListener('click', handleClick);
});

// ✅ Event delegation — one listener on parent
const list = document.querySelector('.list');
list.addEventListener('click', function(e) {
  const item = e.target.closest('.item');  // handles nested elements
  if (!item) return;

  const id = item.dataset.id;
  console.log('Clicked item:', id);

  // Toggle class on clicked item
  item.classList.toggle('selected');
});

// preventDefault — stop default browser behaviour
document.querySelector('form').addEventListener('submit', e => {
  e.preventDefault();  // stop page reload
  validateAndSubmit();
});
✏️ Your Task

Build a to-do list where clicking any item toggles it as 'done'. Use event delegation — one listener on the <ul>, not one on each <li>. Add items dynamically and confirm they also work.
