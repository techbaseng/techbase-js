Phase 1 of 2
String basics and template literals
📖 Concept

Strings are immutable sequences of characters. Create with quotes: single ', double ", or backtick ` (template literal). Template literals support: multiline strings, embedded expressions ${expr}, and tagged templates. Properties: .length. Escape sequences: \n (newline), \t (tab), \' (quote).

script.js
const name = 'Amina';
const course = 'JavaScript';

// Concatenation (old way)
const msg1 = 'Hello, ' + name + '! Welcome to ' + course + '.';

// Template literal (modern — prefer this)
const msg2 = `Hello, ${name}! Welcome to ${course}.`;

// Expressions in template literals
const score = 94;
const msg3 = `Score: ${score} — Grade: ${score >= 70 ? 'A' : 'B'}`;

// Multiline template literal
const email = `
  Dear ${name},

  Your enrollment in ${course} is confirmed.
  Score: ${score}

  Techbase Academy
`;

// String properties
'hello'.length;      // 5
''.length;           // 0 (empty string is falsy)

// Escape sequences
'Line 1\nLine 2';   // newline
'Tab\there';        // tab
"She said \"hi\""; // escaped quote

Phase 2 of 2
String immutability
📖 Concept

Strings are immutable — methods return NEW strings, they don't change the original. Accessing characters: str[0] or str.charAt(0). Comparing: use ===, or .localeCompare() for proper alphabetical ordering. typeof returns 'string'. Strings and numbers: Number('42'), String(42), parseInt('42px').

script.js
let str = 'Hello';
str.toUpperCase();  // 'HELLO'
console.log(str);   // still 'Hello' — immutable!

// Character access
'Hello'[0];             // 'H'
'Hello'.charAt(1);      // 'e'
'Hello'.at(-1);         // 'o' (negative index!)

// String → number
Number('42');           // 42
parseInt('42px');       // 42 (stops at non-digit)
parseFloat('3.14em');   // 3.14
+'42';                  // 42 (unary + operator)

// Number → string
String(42);             // '42'
(42).toString();        // '42'
(3.14159).toFixed(2);  // '3.14' (for display)

// Comparison
'apple' < 'banana';        // true (alphabetical)
'Apple'.localeCompare('apple');  // negative (A before a)
