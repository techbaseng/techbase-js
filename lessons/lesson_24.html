Phase 1 of 2
Array basics and access
📖 Concept

Arrays hold ordered lists of values (any type, mixed). Create with [] or new Array(). Access by index (0-based): arr[0]. Negative with .at(-1). Length: arr.length. Mutable: arr[0] = newVal. Sparse arrays: arr[100] = 'far' creates 101 slots.

script.js
// Creating arrays
const fruits = ['mango', 'guava', 'pawpaw'];
const mixed  = [42, 'hello', true, null, {a:1}, [1,2]];
const empty  = [];
const of5    = new Array(5);  // [empty × 5]
const filled = new Array(5).fill(0);  // [0,0,0,0,0]

// Access
fruits[0];        // 'mango'
fruits[2];        // 'pawpaw'
fruits.at(-1);    // 'pawpaw' (last)
fruits.at(-2);    // 'guava'

// Modify
fruits[1] = 'banana';  // replace
fruits.length;          // 3

// Array.of
Array.of(1, 2, 3);     // [1, 2, 3]

// Array.from
Array.from('hello');    // ['h','e','l','l','o']
Array.from({length:5}, (_,i) => i+1); // [1,2,3,4,5]
Array.from(new Set([1,1,2,2,3]));     // [1,2,3] (unique)

Phase 2 of 2
Adding, removing and spreading
📖 Concept

push() — add to end. pop() — remove from end. unshift() — add to start. shift() — remove from start. splice(i, n, ...items) — remove n items at i, optionally insert. slice(start, end) — copy subset. Spread: [...arr1, ...arr2].

script.js
const arr = [1, 2, 3, 4, 5];

// Adding
arr.push(6);          // [1,2,3,4,5,6] — returns new length
arr.unshift(0);       // [0,1,2,3,4,5,6] — returns new length
arr.push(7, 8, 9);    // add multiple

// Removing
arr.pop();            // removes 9, returns 9
arr.shift();          // removes 0, returns 0

// Splice — add/remove at position
arr.splice(2, 1);          // removes 1 item at index 2
arr.splice(2, 0, 99, 100); // inserts 99,100 at index 2
arr.splice(2, 2, 'X');     // removes 2, inserts 'X'

// Slice — copy (doesn't modify original)
const copy    = arr.slice();       // full copy
const subset  = arr.slice(1, 3);  // items 1-2

// Spread — immutable operations
const arr2 = [...arr, 10, 11];    // add to end
const arr3 = [0, ...arr];         // add to start
const concat = [...arr, ...arr2]; // merge
