Phase 1 of 2
break and continue
📖 Concept

break exits the innermost loop or switch immediately. continue skips the rest of the current iteration and moves to the next. Both work in for, while, do...while, and for...of/in. Neither works in forEach — use for...of instead when you need break.

script.js
// break — exit loop early
for (let i = 0; i < 10; i++) {
  if (i === 5) break;  // exits when i === 5
  console.log(i);      // 0,1,2,3,4
}

// continue — skip iteration
for (let i = 0; i < 10; i++) {
  if (i % 2 === 0) continue; // skip even
  console.log(i); // 1,3,5,7,9
}

// break in while
let found = -1;
const arr = [3, 7, 2, 9, 1];
let i = 0;
while (i < arr.length) {
  if (arr[i] > 8) { found = i; break; }
  i++;
}

// break in switch (always needed!)
switch (x) {
  case 1: doA(); break; // break prevents fall-through
  case 2: doB(); break;
}
✏️ Your Task

Use break to find the first duplicate in an array: [1,3,5,3,2,7] — stop as soon as you find a value you've seen before. Return the duplicate.

Phase 2 of 2
Labelled break
📖 Concept

Labels let you break out of or continue an OUTER loop from inside a nested loop. Syntax: outerLabel: for(...) then break outerLabel. Rarely needed — restructure your code first. Useful for grid searches: find an item and break out of both loops at once.

script.js
// Labelled break — exit outer loop from inner
outer: for (let i = 0; i < 3; i++) {
  for (let j = 0; j < 3; j++) {
    if (i === 1 && j === 1) {
      break outer; // exits BOTH loops!
    }
    console.log(i, j);
  }
}
// logs: 0,0  0,1  0,2  1,0  (then stops)

// Labelled continue
outer: for (let i = 0; i < 3; i++) {
  for (let j = 0; j < 3; j++) {
    if (j === 1) continue outer; // skip to next i
    console.log(i, j);
  }
}
// logs: 0,0  1,0  2,0
✏️ Your Task

Use a labelled break to search a 2D grid (array of arrays) for a target value. Once found, break out of both the row and column loops and log the coordinates.
