Phase 1 of 2
var, let and const
📖 Concept

Three ways to declare variables: var (old — avoid: function-scoped, hoisted, can be re-declared). let (modern — block-scoped, can be reassigned, not hoisted to use). const (modern — block-scoped, cannot be reassigned, must be initialised). Rule: use const by default; use let only if you need to reassign; never use var.

script.js
// const — value won't change
const PI = 3.14159;
const COURSE = 'JavaScript';
// PI = 3.14;  // ❌ TypeError: Assignment to constant variable

// let — value may change
let score = 0;
score = score + 10;  // ✅ reassignment OK
let age = 20;
age++;               // ✅ also fine

// var — AVOID (unpredictable scoping)
var x = 1;
{
  var x = 2;  // same variable! overwrites outer x
  let y = 3;  // block-scoped — only exists here
}
console.log(x); // 2 — surprising!
// console.log(y); // ❌ ReferenceError — y not in scope

// const with objects/arrays — the REFERENCE is const, not the content
const student = { name: 'Amina', score: 94 };
student.score = 95;     // ✅ modifying property is fine
// student = {};         // ❌ can't reassign the variable

Phase 2 of 2
Scope and hoisting
📖 Concept

Scope = where a variable is accessible. Block scope ({ }): let and const only exist inside the block. Function scope: var and let/const inside a function only exist there. Hoisting: var declarations are moved to the top of their scope (but not their value — gives undefined). let/const are in a Temporal Dead Zone until declared.

script.js
// Block scope with let
{
  let blockVar = 'inside';
  console.log(blockVar);  // ✅ 'inside'
}
// console.log(blockVar);  // ❌ ReferenceError

// Hoisting with var (confusing!)
console.log(myVar);  // undefined (not an error!)
var myVar = 'hello';

// let/const — Temporal Dead Zone
// console.log(myLet);  // ❌ ReferenceError (not undefined!)
let myLet = 'hello';

// Function scope
function outer() {
  let x = 10;
  function inner() {
    console.log(x);  // ✅ inner can access outer's x (closure)
  }
  inner();
}
✏️ Your Task

Create a variable inside an if block using let. Try to access it outside — see the ReferenceError. Then replace let with var and try again — it works, but this is why var is dangerous!

    const lines = [];
