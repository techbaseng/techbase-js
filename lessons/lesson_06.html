Phase 1 of 2
Single-line and multi-line comments
📖 Concept

// starts a single-line comment — everything after is ignored. /* ... */ makes a multi-line comment. Comments are not executed — use them to: explain WHY (not what), document function parameters, disable code temporarily, add TODO notes. Good code explains itself; comments explain intent.

script.js
// Single-line comment — use for brief explanations
let tax = 0.075; // 7.5% VAT rate for Nigeria

// Explain WHY, not WHAT (what is visible in the code)
// Bad: // add 1 to count
count++;
// Good: // increment to account for the off-by-one in legacy API
count++;

/* Multi-line comment — use for longer explanations
   or temporarily disabling a block of code */

/**
 * JSDoc comment — documents a function (shows in editor tooltips)
 * @param {number} price  - Base price before tax
 * @param {number} rate   - Tax rate as decimal (e.g. 0.075)
 * @returns {number} Total price including tax
 */
function withTax(price, rate) {
  return price * (1 + rate);
}

Phase 2 of 2
Comment best practices
📖 Concept

Good comments: explain logic that isn't obvious, document edge cases, add TODOs for future work. Bad comments: restate what the code already says (// add 1), never updated so they become wrong, commented-out code left in forever. Comment code you'd have to stop and think about; don't comment the obvious.

script.js
// ✅ GOOD — explains non-obvious business logic
// Prices are stored in kobo (1 NGN = 100 kobo) to avoid
// floating-point rounding errors in financial calculations
const priceInKobo = 150000; // ₦1,500.00

// ✅ TODO comment — signals future work
// TODO: replace with API call once backend is ready
const students = [{ name: 'Amina', score: 94 }];

// ✅ Explain a workaround
// eslint-disable-next-line — false positive, not a real circular ref
import { helper } from './utils';

// ❌ BAD — restates the code
// set x to 5
let x = 5;

// ❌ BAD — commented-out code with no explanation (delete it!)
// let oldVersion = fetch('/api/v1/data');  <-- what was this?
