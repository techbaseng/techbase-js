Phase 1 of 2
Four output methods
📖 Concept

JS has 4 ways to output data: console.log() — DevTools console (debugging). alert() — browser popup. document.write() — writes to page (avoid — overwrites everything after load!). innerHTML — updates a specific element (best for showing results).

script.js
// 1. Console — for debugging, not users
console.log('Hello');
console.warn('Watch out!');
console.error('Something broke');
console.table([{a:1},{a:2}]);

// 2. Alert — popup (blocks page, avoid overusing)
alert('Message to user');

// 3. innerHTML — update an element
document.getElementById('output').innerHTML = '<strong>Result: 42</strong>';

// 4. document.write — only before page loads
// document.write('<p>Hello</p>');  // ⚠️ never call after load!

// 5. textContent — safer than innerHTML (no HTML injection risk)
document.getElementById('output').textContent = 'Plain text only';

Phase 2 of 2
innerHTML vs textContent
📖 Concept

innerHTML parses HTML tags — great for rich output but risk of XSS injection if content comes from users. textContent treats everything as plain text — safe from injection but can't render HTML. Rule: use textContent for user-supplied data, innerHTML for your own HTML strings.

script.js
// innerHTML — renders HTML
el.innerHTML = '<strong>Bold</strong> text';  // ✅ works

// Danger — never use with user input!
// el.innerHTML = userInput;  // ❌ XSS risk!

// textContent — safe from injection
el.textContent = '<strong>Bold</strong>';
// Literally shows: <strong>Bold</strong>

// For user input always use textContent
let userComment = '<script>alert("hacked")<\/script>';
el.textContent = userComment;  // Safe — shows as plain text

// insertAdjacentHTML — faster than innerHTML for appending
el.insertAdjacentHTML('beforeend', '<p>New paragraph</p>');
✏️ Your Task

Test XSS protection: make an input where users can type HTML. Display the value using both innerHTML and textContent. Notice that innerHTML renders the tags while textContent safely shows them as text.
