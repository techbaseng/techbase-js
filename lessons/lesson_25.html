Phase 1 of 2
map, filter and find
📖 Concept

map(fn) — transforms every element, returns new array of same length. filter(fn) — keeps elements where fn returns true. find(fn) — returns first matching element (or undefined). findIndex(fn) — returns first matching index (-1 if none). some(fn) — true if any match. every(fn) — true if all match.

script.js
const students = [
  {name:'Amina', score:94, course:'JS'},
  {name:'Chidi', score:67, course:'CSS'},
  {name:'Tunde', score:52, course:'JS'},
  {name:'Fatima', score:88, course:'Python'},
];

// map — transform
const names  = students.map(s => s.name);         // ['Amina','Chidi',...]
const grades = students.map(s => ({
  ...s,
  grade: s.score >= 70 ? 'Pass' : 'Fail'
}));

// filter — keep matching
const passed = students.filter(s => s.score >= 70);     // Amina, Fatima
const jsOnly = students.filter(s => s.course === 'JS');  // Amina, Tunde

// find — first match
const topStudent = students.find(s => s.score > 90);  // Amina
const notFound   = students.find(s => s.score > 99);  // undefined

// some, every
students.some(s => s.score > 90);   // true (Amina)
students.every(s => s.score >= 50); // true (all pass 50)

Phase 2 of 2
reduce, sort and flat
📖 Concept

reduce(fn, initial) — accumulates a single value. sort(compareFn) — sorts IN PLACE (always provide a compare function). flat(depth) — flattens nested arrays. flatMap(fn) — map then flat. forEach(fn) — runs fn for each element, returns undefined (no chaining!).

script.js
const scores = [94, 67, 52, 88, 71, 43, 79];

// reduce — accumulate
const total   = scores.reduce((sum, s) => sum + s, 0);          // 494
const average = total / scores.length;                           // 70.57
const max     = scores.reduce((m, s) => Math.max(m, s), -Inf);  // 94
const histogram = scores.reduce((acc, s) => {
  const bucket = Math.floor(s / 10) * 10;
  acc[bucket] = (acc[bucket] || 0) + 1;
  return acc;
}, {});

// sort — always provide compareFn!
scores.sort((a, b) => a - b);  // ascending
scores.sort((a, b) => b - a);  // descending
['banana','apple','mango'].sort(); // alphabetical (no fn needed)

// flat / flatMap
[[1,2],[3,4],[5]].flat();          // [1,2,3,4,5]
[1,2,3].flatMap(n => [n, n*2]);    // [1,2,2,4,3,6]

// forEach — side effects only
students.forEach(s => console.log(s.name));
✏️ Your Task

Use reduce to build a leaderboard object that groups students by grade: {A:[...], B:[...], C:[...]}. Then sort students by score descending using sort.
