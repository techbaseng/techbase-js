Phase 1 of 2
Statements and semicolons
📖 Concept

A JavaScript statement is a single instruction. Statements end with a semicolon (;) — technically optional due to ASI (Automatic Semicolon Insertion) but always recommended. Multiple statements can be on one line separated by semicolons. A block { } groups statements together — used in functions, if/else, loops.

script.js
// Each line is a statement
let x = 5;
let y = 10;
let z = x + y;

// Multiple statements on one line (avoid — hard to read)
let a = 1; let b = 2; let c = a + b;

// Code block — groups statements
if (x > 3) {
  let message = 'x is big';
  console.log(message);      // two statements in one block
}

// Statement types:
let name = 'Tunde';          // declaration
name = 'Amina';              // assignment
console.log(name);           // expression statement
// if (name) { ... }         // control flow
// function greet() { ... }  // function declaration

Phase 2 of 2
White space and line length
📖 Concept

JS ignores extra whitespace — use it for readability. Convention: 2 or 4 spaces for indentation. Lines should be under 80 characters. Separate logical sections with blank lines. Consistent style matters in team projects — tools like Prettier autoformat code automatically.

script.js
// Bad — cramped and hard to read
function add(a,b){return a+b;}

// Good — spaced and readable
function add(a, b) {
  return a + b;
}

// Long expressions — break onto multiple lines
const result = firstValue
  + secondValue
  + thirdValue;

// Object literal formatting
const student = {
  name:    'Amina',
  course:  'JavaScript',
  lessons: 46,
};

// Chain methods — each on its own line
const output = [1, 2, 3, 4, 5]
  .filter(n => n > 2)
  .map(n => n * 2)
  .join(', ');
