Phase 1 of 2
Template literal power
📖 Concept

Template literals use backticks. Embed any expression with ${expr}. Multi-line without escape sequences. Nested template literals: `outer ${`inner ${val}`}`. Ternary inside: `${score >= 70 ? 'Pass' : 'Fail'}`. Method calls: `${arr.join(', ')}`. Object property: `${user.name}`.

script.js
const name = 'Amina';
const score = 94;

// Basic interpolation
`Hello, ${name}! You scored ${score}.`

// Expression — any JS expression works
`${score >= 70 ? 'Pass 🎉' : 'Fail 😔'}`
`${Math.round(score / 10) * 10}%`
`${name.toUpperCase()}`

// Multi-line (literal newlines preserved)
const email = `
  Subject: Course Update

  Dear ${name},
  Your latest score is ${score}.
`;

// Building HTML
const items = ['HTML', 'CSS', 'JavaScript'];
const html = `
  <ul>
    ${items.map(item => `<li>${item}</li>`).join('\n    ')}
  </ul>
`;

// Nested template literals
const report = `${name}: ${score >= 70 ? `Grade A — ${score > 90 ? 'Distinction' : 'Pass'}` : 'Needs improvement'}`;

Phase 2 of 2
Tagged templates
📖 Concept

A tagged template is a function that processes a template literal. The tag function receives the string parts and interpolated values separately. Used by: styled-components (CSS-in-JS), GraphQL queries, SQL template literals (safe from injection), and i18n libraries.

script.js
// Tagged template — function + template literal
function highlight(strings, ...values) {
  return strings.reduce((result, str, i) => {
    const val = values[i - 1];
    return result + `<strong>${val}</strong>` + str;
  });
}

const name = 'Amina'; const score = 94;
highlight`Student ${name} scored ${score} points!`;
// 'Student <strong>Amina</strong> scored <strong>94</strong> points!'

// Safe SQL template (prevents injection)
function safeSQL(strings, ...vals) {
  const escaped = vals.map(v => typeof v === 'string' ? `'${v.replace(/'/g,"''")}'` : v);
  return String.raw({ raw: strings }, ...escaped);
}
safeSQL`SELECT * FROM users WHERE name = ${"O'Brien"}`;

// String.raw — backslashes not processed
String.raw`C:\Users\Amina`;  // 'C:\\Users\\Amina' — great for Windows paths
