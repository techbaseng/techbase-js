Phase 1 of 2
BigInt basics
📖 Concept

BigInt handles integers larger than Number.MAX_SAFE_INTEGER. Create by appending n: 42n, or with BigInt('12345678901234567890'). Cannot mix BigInt and regular Number arithmetic — must convert explicitly. No floating-point BigInt. typeof 42n === 'bigint'.

script.js
// Regular number loses precision beyond MAX_SAFE_INTEGER
const big = 9007199254740991;
console.log(big + 1);   // 9007199254740992
console.log(big + 2);   // 9007199254740992 (same! precision lost)

// BigInt is precise
const bigN = 9007199254740991n;
console.log(bigN + 1n); // 9007199254740992n ✅
console.log(bigN + 2n); // 9007199254740993n ✅

// Create BigInt
42n;                          // literal
BigInt(42);                   // from number
BigInt('12345678901234567890'); // from string

// Arithmetic — all operands must be BigInt
10n + 5n;   // 15n
10n - 5n;   // 5n
10n * 5n;   // 50n
10n / 3n;   // 3n (no remainder — truncates!)
10n % 3n;   // 1n
10n ** 3n;  // 1000n

// No mixing!
// 10n + 5;  // ❌ TypeError
BigInt(10) + 5n;  // ✅ convert first
Number(10n) + 5;  // ✅ convert to Number (risks losing precision)

Phase 2 of 2
BigInt comparison and conversion
📖 Concept

BigInt can be compared with === (type-sensitive) and == (coerces). Use <, >, <=, >= to compare BigInt with Number. Convert with Number(bigInt) (loses precision if too large) or bigInt.toString(). JSON doesn't support BigInt — need custom serialisation.

script.js
// Comparison
1n === 1;   // false (different types)
1n == 1;    // true  (type coercion)
1n < 2;     // true  (comparison with Number allowed)
2n > 1;     // true

// Sorting mixed arrays
const mixed = [3, 1n, 2, 4n];
// Can't sort directly — use conversion
mixed.sort((a,b) => Number(a-b)); // ❌ mixing in -

// Conversion
Number(9007199254740993n);  // 9007199254740992 (precision loss!)
(123n).toString();          // '123'
(255n).toString(16);        // 'ff' (hex)

// JSON — BigInt not supported
// JSON.stringify({x: 42n});  // ❌ TypeError
// Workaround:
const obj = {x: 42n};
JSON.stringify(obj, (key, val) =>
  typeof val === 'bigint' ? val.toString() + 'n' : val
);
// '{"x":"42n"}'
